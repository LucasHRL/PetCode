# 🐾 PetCode

### Plataforma de Planos de Saúde Veterinários Inteligentes

O **PetCode** é uma aplicação web desenvolvida como projeto acadêmico durante o curso de Engenharia de Software.

A proposta do projeto é simular uma plataforma de planos de saúde veterinários, oferecendo aos tutores ferramentas e funcionalidades para auxiliar no cuidado e acompanhamento de seus pets.

## 🎯 Objetivo

Desenvolver uma experiência digital que reúna informações, ferramentas interativas e simulação de planos de saúde veterinários em uma única plataforma.

## 🚀 Funcionalidades

- 🧠 Simulador de Plano Ideal
- 🧮 Calculadora de Idade Humana do Pet
- 📍 Busca simulada de clínicas parceiras
- 💳 Simulação de planos de saúde
- 👤 Cadastro e login de usuários
- 🐶 Cadastro e gerenciamento de pets
- 📋 Gerenciamento de planos
- 👨‍💼 Área administrativa
- 📚 Conteúdos educativos sobre cuidados com animais
- 💡 Curiosidades sobre o mundo animal
- 📱 Interface responsiva
- ✨ Animações e elementos interativos

## 🤖 Desenvolvimento com Inteligência Artificial

O PetCode foi desenvolvido **100% com auxílio de Inteligência Artificial**, utilizando a IA como ferramenta central para a geração do código e construção da aplicação.

O desenvolvimento foi conduzido através da **engenharia de prompts**, sendo a equipe responsável pela concepção do projeto, definição dos requisitos, criação e refinamento dos prompts, direcionamento das funcionalidades, testes e validação dos resultados gerados.

Durante o desenvolvimento, a Inteligência Artificial foi utilizada para:

- Geração do código;
- Estruturação da interface;
- Implementação das funcionalidades;
- Criação da lógica da aplicação;
- Correção de problemas;
- Implementação de melhorias;
- Desenvolvimento da experiência visual.

O projeto representa uma experiência prática de utilização de **Inteligência Artificial e Engenharia de Prompts aplicada ao desenvolvimento de software**.
